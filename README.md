# Infrastructure

## Описание проекта инфраструктуры

Инфраструктура проекта представляет собой современное, безопасное и масштабируемое решение для развертывания микросервисной архитектуры. Она включает в себя все необходимые компоненты для обеспечения стабильной работы системы персонализированных рекомендаций, включая базу данных, кэширование, мониторинг и API-шлюз.

Основные компоненты инфраструктуры:

- **PostgreSQL 15** - основная база данных для хранения пользовательских данных, профилей и рекомендаций
- **Grafana** - система мониторинга и визуализации метрик
- **FastAPI** - API-шлюз для взаимодействия с клиентами
- **Docker Compose** - оркестрация контейнеров для локальной разработки и production развертывания

## Оптимальность для production среды

Инфраструктура спроектирована с учетом требований production среды и включает в себя следующие оптимизации:

### Ресурсы и производительность

- Ограничения ресурсов для PostgreSQL: 1 CPU, 2GB памяти
- Использование кэширования для ускорения доступа к данным
- Оптимизация подключения к базе данных через connection pooling
- Настройка производительности PostgreSQL через `postgresql.conf`

### Масштабируемость

- Микросервисная архитектура позволяет масштабировать компоненты независимо
- Поддержка горизонтального масштабирования через Docker Swarm
- Возможность увеличения ресурсов для отдельных сервисов при росте нагрузки

### Надежность

- Healthcheck для PostgreSQL для обеспечения отказоустойчивости
- Graceful degradation при частичных отказах
- Регулярные резервные копии базы данных
- Возможность быстрого восстановления из резервных копий

## Безопасность для production среды

Инфраструктура обеспечивает высокий уровень безопасности, соответствующий требованиям production среды:

### Управление секретами

- Использование Docker secrets для хранения конфиденциальных данных
- Разделение секретов для разных компонентов (PostgreSQL, Grafana, приложения)
- Автоматическая ротация секретов через Makefile команды
- Шифрование паролей при передаче в контейнеры

### Безопасность подключений

- Использование защищенных переменных окружения для передачи паролей
- Настройка SSL для подключений к базе данных (опционально)
- Ограничение доступа к сервисам через сети Docker

### Безопасность Grafana

- Отключение формы входа в пользу аутентификации через прокси
- Использование строгих cookie политик
- Отключение возможности встраивания для защиты от XSS
- Настройка ролевой модели доступа

### Общая безопасность

- Использование минимальных образов Alpine Linux для контейнеров
- Ограничение прав доступа к файлам секретов (chmod 600)
- Регулярная ротация паролей
- Логирование всех операций для аудита

## Вычислительные потребности

Для стабильной работы инфраструктуры в production среде рекомендуются следующие минимальные требования:

### Рекомендуемая конфигурация сервера

- **CPU**: 4 ядра (2 для PostgreSQL, 2 для приложений)
- **RAM**: 8GB (4GB для PostgreSQL, 4GB для приложений и кэша)
- **Disk**: 50GB SSD (PostgreSQL \+ резервные копии)
- **Network**: 100Mbps

### Распределение ресурсов

- PostgreSQL: 2 CPU, 4GB RAM
- Приложения (FastAPI): 2 CPU, 4GB RAM
- Grafana и мониторинг: 0.5 CPU, 1GB RAM
- Резервные копии и фоновые задачи: 0.5 CPU, 1GB RAM

## Мониторинг и наблюдаемость

Инфраструктура включает в себя встроенные механизмы мониторинга:

### Grafana

- Визуализация метрик производительности
- Мониторинг подключений к базе данных
- Отслеживание активных пользователей
- Мониторинг времени выполнения ML-запросов

### Логирование

- Структурированное логирование всех операций
- Возможность настройки уровней логирования
- Логирование ошибок и предупреждений

## Резервное копирование и восстановление

Инфраструктура обеспечивает надежное резервное копирование данных:

### Ежедневные резервные копии

- Полные резервные копии всех баз данных
- Дифференциальные резервные копии для ускорения процесса
- Автоматическое удаление резервных копий старше 7 дней
- Возможность сохранения резервных копий в S3 (опционально)

### Восстановление

- Простая процедура восстановления из резервных копий
- Возможность восстановления на определенную дату
- Проверка целостности резервных копий

## Управление инфраструктурой

Инфраструктура предоставляет удобные инструменты для управления:

### Makefile команды

- `make secrets` - генерация секретов
- `make up` - запуск всех сервисов
- `make down` - остановка сервисов
- `make backup` - создание резервной копии
- `make rotate-secrets` - ротация паролей
- `make status` - проверка статуса сервисов

### Bash скрипты

- `bash_start.sh` - автоматический запуск всей инфраструктуры
- `scripts/backup-db.sh` - скрипт резервного копирования
- `scripts/rotate-secrets.sh` - скрипт ротации секретов
- `scripts/set-app-password.sh` - скрипт установки паролей приложений
